# Fig3：Gaussian高斯表面通路如何支撑有效结合预测

## 任务与图间分工

高斯通路在本图明确指Gaussian表面建模通路及其中的pair消息。Fig2负责与其他方法相比的主任务表现；本Fig3负责表面通路的实际计算作用和跨构象正确性；Fig4区分原始结合score的直接应用与Gaussian hidden的变构相关读出。不在本图新增hidden主结合任务线性探针，不混入突变敏感性或变构标签。

这是对已完成实验的重新汇总与绘图，不新增训练或前向，不声称新预注册。原12条件实验和原统计协议作为raw来源保留。新版本命名为fig3_gaussian_surface_v20261021，旧Fig3和先前binding-reliability版均不覆盖。

## 干预定义：全部来自真实执行代码

| 条件 | 实际注入位置与操作 |
|---|---|
| baseline / identity | 原模型与无改动重放；逐残基概率精确一致 |
| surface_half / surface_zero | 残基gate/update和最终fusion输入中surface context部分乘0.5或0，保留残基部分和其余网络；称高斯表面反馈通路干预 |
| P_half / P_zero | 每轮pair模块原生LayerNorm前保留single-surface base，只将pair correction乘0.5或0；不是把整个表面通路都清零 |
| M_zero | 单残基投影context_proj输入置零 |
| MP_zero | M和P两处同时置零 |
| P_top | 用原生score前ceil(10%输入长度)残基的模型质心选8Å内表面点，仅在这些点执行P_zero；各轮使用同一掩码，不读取结合标签 |
| P_random101/211/307 | 每case随机选与P_top完全相同数量的表面点，执行相同pair截断 |

“高分区域pair定向扰动”不改名成“权重最大的pair被删除”：实际mask选择的是预测候选附近的表面点。随机对照匹配数量，不声称空间形状、message范数或暴露度同时匹配。表面反馈移除的效应与pair分支移除的效应分开归因。

## 六个panel及统一视觉语义

### A：表面通路依赖性

横轴在每种结构状态内依次为surface context保留100%、50%、0%；纵轴为全有效残基AP。每条细线连接同system，半透明点与小提琴为实际system分布，粗线/菱形为system均值及95%区间，内竖线为IQR。三状态固定颜色：holo紫、apo赭、AF2蓝。顶部直接给system数和完整截断AP损失。无需另分一个panel重复画配对损失。

### B：强度响应

横轴为实际消息/反馈移除比例0、50%、100%；纵轴为AP损失百分点。颜色编码surface feedback和pair message两注入点，线型/点形编码三状态，区间和淡带编码均值不确定性。只有三个真实剂量点，直线仅连接观测，不拟合平滑剂量机制，不把50%输入衰减叫50%性能损失。

### C：定向局部pair截断如何破坏位点优先级

同一坐标系内，横轴是P_top相对三随机种子均值的额外AP损失，纵轴是额外流失的正确原生top10%候选/固定预算。点为system；边缘直方图显示分布；白菱形及横纵区间是配对均值。右上背景直接表示两种损失共现，不裁去其他象限。

正确候选流失：原生top10%中的真界面位置，在干预top10%中消失的数量/预算。它不等于precision下降，因为可能流失一个真阳性又补进另一个真阳性。

内嵌的正/负残基优先级变化用同一数据补充解释：priority=平均秩/L，高分对应高priority；loss=native priority−perturbed priority，正表示失去优先级。图中是target loss−random mean loss。严格单调地整体压低score不会改变AP、秩或这些候选集合，因此这些指标区分“概率变小”和“排序信息被破坏”。

正负位置的平均秩变化是同一全体排序重分配的互补分解，不作为两项独立生物验证。

### D：跨构象的绝对正确性与配对变化

横轴四模型，分apo/AF2；纵轴同共同位置、同参考标签的AP。每system细线把左侧holo参考连到右侧未结合输入；空心为holo均值，实心菱形及区间为未结合均值，小提琴展示未结合AP分布。一个坐标系同时给绝对性能、变化方向、模型对照、异质性与区间，不再上下堆两张不同纵轴图。

### E：跨构象重合与正确性是否统一

横轴top10%候选Jaccard，纵轴两状态共同选中的真界面位置数/预算。四模型同system同预算，点云为system，菱形和两轴区间为均值。虚线y=2J/(1+J)是相同预算时“重合候选全部正确”的上界；它是解释性上界，不是拟合模型或随机基线。模型均值也位于该上界下，因为函数凹性保留上界关系。灰色上方为不可能区域，不能称置信区间。

### F：同一结构上的空间与排名解释

从全部1862例导出完整候选清单。解释实例限定AF2、native AP>=0.7、surface干预损失>0、target损失>随机均值，再按native AP、surface损失、target额外损失、长度四项百分位距各自中位数的总和最小选择；case_id破并列。本规则是在结果后选择有代表性的正向解释实例，不用作独立验证，也不选最大损失例。

三幅图使用模型实际采样surface点和相同PCA视角/尺度：native、local pair off、surface off；颜色是最近模型残基质心对应的结合score，不是模型另输出的surface概率；金圈是真参考界面残基，局部截断区域用细边标记。每幅给AP和固定top10%命中数。下方同轴散点展示真实界面残基在两种干预下的排名流失，横轴为原生排序位置，0–10%带标明候选预算。空间视图和排名变化对应同一套位置，不挑局部视野。

## 检验与交付

重算全部22344 AP并与原表对照；独立复核1862例的8Å局部掩码与三随机掩码等数量；重放新system点估计、固定预算候选、示例秩变化与配对迁移队列。源表包含全部干预、未被主图重点使用的M/MP条件、全部正负增量、完整选择清单与原协议。原始图、binding-reliability版及其数据不变。

主结论：Gaussian表面建模是有效结合预测的重要计算支撑；局部高分候选附近的pair消息对维持正确优先级更重要；模型在未结合/预测结构上仍能保留较高的界面识别与正确候选。生物变构读出留给Fig4。
