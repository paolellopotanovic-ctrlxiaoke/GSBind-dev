# Fig3 结合计算可靠性：分析前冻结定义

本轮只分析主结合任务，不加入变构标签、SSM或功能效应。使用现有四模型原始预测，无新训练、方向翻转、融合或测试阈值调优。新目录并行存在，旧图/旧代码不覆盖。

## 人群与固定参照

起始为874个apo/AF2 directed cases，按system_id+receptor_side关联988个holo记录。从各自物化PDB的指定链及input_residue_ids读取真实CA序列/坐标，不能把PDB编号直接当UniProt统一映射。

全局仿射缺口序列对齐：match2、mismatch-1、open-5、extend-0.5，末端缺口免费。PDB读取包括manifest所指定的ATOM/HETATM残基，硒代甲硫氨酸MSE规范为M，不因为它写在HETATM而丢整条蛋白。多个最优对齐有不同映射时标记歧义；主分析要求唯一最优对齐、对应残基身份≥95%、身份一致的配对残基覆盖双方各≥80%，至少10个有效共同位置，且固定标签含正负两类。所有874条记录保留审计，不根据预测收益排除。确定性首个对齐的人群作歧义敏感性，不称唯一映射。

共同位置使用holo已有绑定标签及两状态有效mask；state原始标签仅作敏感性端点。该标签是当前holo参考的官方接口并集，不自动等于某一个partner特异界面。坐标用身份一致共同CA进行Kabsch全局对齐，在同一变换下测量整体和参考界面局部位移。不用每模型预测决定对齐或参照。

## 九面板及完整补充数据

A 同目标的holo→apo/AF2 AP，四模型同位置同标签，区分输入状态；报告状态配对变化而非重复Fig2总榜。

B 固定参考界面平均CA位移与state AP增量（GSbind−PeSTo）。保留全部位移连续散点；描述性固定区间<1、1–2、≥2 Å，不按结果改边界。其他两基线完整导出。

C 跨状态候选的正确保持：固定全共同链top10%候选；两状态共同选中且真阳性的位置数/K为主，同时保留Jaccard、各状态precision、正确位置交集/并集等。不只用一致性替代正确性；固定K=5/10/20/40也完整保存。

D 固定残基检查预算K=5/10/20/40的正确命中与precision，预算超长度时用min(K,L)并记录实际K。

E 按分数检查至覆盖50%/80%固定参考界面所需位置比例。边界同分全部纳入（保守tie规则），该指标是回顾性覆盖成本，不是假装部署时已知真值的停止条件。

F 固定几何候选区域：每个CA为中心、8 Å球包含自身，区域优先级为区域内最高min(5,n)个score的均值；贪心排序，候选区域与已选区域的overlap/min(size)大于0.5则跳过。前1/3/5个区域报告真界面recall与实际覆盖位置比例，不把“更多面积带来的更多命中”直接称更优。仅称空间候选区域，不称配体口袋。区域在完整共同坐标输入上生成，无真值参与。

G AF2输入置信与候选正确性：固定top10%候选，根据其平均CA B-factor中的pLDDT描述，固定<70、70–90、≥90组；只有明确AF2输入才使用，不把apo晶体B-factor叫pLDDT。直接模型比较使用GSbind候选置信定义的共同case组，各模型独立定义的组另外导出。无置信数据单列。不是结合概率校准，不依据结果选择pLDDT阈值。

H 结构条件选择性：按CA8Å邻居数分成固定0–7、8–15、16–23、≥24四层，每case每层正负位置对的AUROC，按该case可比较正负对数量加权。这衡量局部packing相近情况下的结合区分，非完全匹配、非结构基线训练、非因果控制；层支持度完整导出。

I 配对结构示例：在合格AF2例中，按GSbind状态AP、界面位移、正例比例各自的总体百分位距0.5之和最小选代表例，case_id破并列。无模型间最大增益筛选。保存holo/AF2对齐坐标、标签、四模型score、固定K候选和实际数值；展示遗漏，不挑局部区域美化。

## 汇总与不确定性

点估计统一system等权，system内directed cases等权；主分析按system配对bootstrap10000次，固定种子20261021。A配对holo/state，其他面板所有模型在同一有效人群比较。置信区间条件于既有模型，不包括训练方差。保留case均值、system数、case数、全部基线差值和所有不利结果；不拿最弱或逐case最优基线充当统一对照。连续图不把平滑趋势视为显著性检验。

主图聚焦主要问题，完整人群、预算和来源表作为补充。若某面板没有优势，照实呈现或放补充并明确主文claim范围，不能改标签/阈值把负结果转正。可将主图压缩至有独立问题和实际证据的六面板，不为九格凑数。
