# Fig3：任务贡献、视觉表达与联合收益修订

## 中心故事

实际使用时，待研究蛋白通常只有未结合结构或预测结构。我们希望从这些输入中定位结合界面，并优先检查较少的位置，而不是只在已结合结构上给出较高分数。

本图检验的是：**保持同一参考界面和残基对应关系后，GSBind能否把结合识别能力转化为更多正确候选、更少的界面搜索负担，以及同一体系中的联合收益。**标签来自holo参考的官方结合界面并集。因此，这里直接支持蛋白相互作用界面定位，不等于已经验证小分子口袋、变构机制、结合自由能或突变实验效应。

## 每个面板承担的独立任务

| 面板 | 任务问题与展示 | 可写出的贡献 |
|---|---|---|
| A | 同体系holo→apo/AF2，固定标签与配对位置 | 非结合输入上仍保有较高绝对结合识别能力；AF2/apo相对PeSTo AP分别+0.0522/+0.0530 |
| B | 全部case的局部界面位移与AP增量 | 交代优势在哪些结构变化范围成立；不将位移与增量的关系当因果或全区间优胜 |
| C | 两状态共同选中的真界面残基/固定预算 | 不是任意排序一致，而是保住正确的结合候选；AF2/apo增量+7.14/+4.17个百分点 |
| D | 固定检查5/10/20/40个位置的界面命中率 | 相同位置预算下，AF2前10命中率81.0% vs PeSTo75.1%；不是实际湿实验成功率 |
| E | 达到50%/80%参考界面召回所需检查比例 | 80%召回时AF2/apo平均检查比例相对PeSTo减少9.43%/16.60%；回顾性排序效率，不是部署停止规则 |
| F | 前1/3/5个几何区域的召回与真实覆盖面积 | 将残基排名落到空间区域；AF2前3区域37.8% vs33.8%召回，覆盖比例13.69% vs13.59%；区域不是配体口袋 |
| G | 同一批AF2置信度分组内的候选正确性 | 提供结构置信度背景与可用性解释；不硬写所有置信度组显著优胜 |
| H | 相近粗packing层内的正负界面残基区分 | 优势不只体现为粗packing分组间差别；不是完整结构因素调整，也不是高斯分支因果归因 |
| I | 每体系同时比较AP增量和80%召回检查比例节省 | 高准确性和较低搜索负担在同一批体系中兑现；全部体系、全部基线均展示 |

六面板保留A/C/D/E/F/H（重新标为a–f），围绕“输入迁移→正确候选→筛选效率→空间定位→packing内区分”组织。九面板加入结构变化范围、置信度背景和联合收益，不把九个相关分析当成九次独立复现。

## I：完整总体的联合收益

先在每个input_state×system×model内等权平均该体系的directed case指标，再做模型间差值：

- 横轴：GSBind AP − comparator AP。
- 纵轴：comparator 80%-recall cost − GSBind 80%-recall cost。
- 右上角严格要求两者均大于0；任一差值恰为0单列boundary_tie，不算严格双赢。
- 其他三个象限和边界点全部保留。各基线使用相同体系，不用每蛋白挑最好方法。
- 同一状态内对所有基线使用相同的10000次system bootstrap索引，seed=20261021。区间是双赢体系比例的百分位区间。

I体现收益的共现与广度，不重新提供独立于A/E的验证。相对PeSTo的双赢比例点估计过半，但区间跨50%，不能声称已经证明总体双赢概率显著超过一半。主优势仍由A/C/E/H的配对平均增量支撑。

原I采用7yva中位代表案例，但GSBind和PeSTo均为top10命中9/10，ScanNet AP更高，无法直观解释本图中心贡献。该例及其选择过程移至补充，仅解释预测形态，不被另选“最好案例”替代。

## 视觉设计与可追溯性

采用更高对比度的蓝/玫红/青绿/赭黄，跨面板固定方法颜色与状态条。经逐条回应comment3后，A/C/H升级为体系分布、箱线和均值区间，D升级为模型×预算均值/IQR矩阵，E补齐10%–90%召回成本曲线，F升级为区域数×模型的面积/召回气泡图，另保留带两轴区间的前沿图；G直接列出21/170/527个case，叠加分布和均值区间。完整设计与原批注对应见FIGURE3_COMMENT_RESPONSE_AND_DENSE_DESIGN_CN_20261021.md。

字幕中的“节省9.43%/16.60%”计算为(基线平均成本−GSBind平均成本)/基线平均成本，是均值之比，不是体系相对节省百分比的平均数。

这次修订不改模型、分数、权重、纳入规则、参考标签、预算或分箱。I为原分析完成后的描述性扩展，不冒称预注册。源数据包含逐体系AP、成本、两种增量、全部象限计数、比例区间、测试与验证记录。
