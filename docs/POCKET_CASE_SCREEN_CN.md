# 更集中定位变构口袋的候选案例

**当前论文候选图已简化**：`1ZA2_pocket_comparison.png/pdf`只保留top5%单行，依次为来源口袋注释、score、structure、hidden；恢复红色命中、橙色遗漏、蓝色注释外高分、灰色背景，不再用单独界面颜色。top10%与界面核对仍保留于底表和历史分析文件，不进入这张当前候选图。蓝色仅表示未命中当前口袋注释，不能直接解释为无生物学意义。下文多阈值及界面配色描述记录分析过程，不代表当前版式。

已对当前AlloBench完整OOF预测进行**事后说明性案例筛选**。在原始来源口袋至少5个位点、映射位点均可评价的范围内，共筛查1506条来源记录、357个蛋白。每条记录使用自己的来源口袋注释，不将多条记录拼成一个更容易命中的口袋；各方法使用同一全蛋白top5%/top10%预算。不重新训练或选择checkpoint。

全部筛查结果见 `figures/structural_cases/pocket_screen/ALL_SOURCE_POCKET_SCREEN.csv`，不能把筛出的最佳案例解释成平均性能、独立验证或新的口袋发现。

### 哪个更适合主文？

**ATCase / 1ZA2是当前较清晰的主文候选**：前8个位置中6个位于CTP注释口袋，另外2个注释外高分仍全部显示。6个命中也都在源配体的6Å范围内；CA距离8Å图的最大连通分量有6个位置。前10%并不完美：7/16命中，precision43.8%、recall58.3%。结构来自野生型E. coli aspartate transcarbamoylase与CTP、carbamoyl phosphate复合物，DOI `10.1073/pnas.0503742102`；本图只显示注释对应调节链B与该链CTP，完整催化/调节装配体未显示，不能把链B画成含催化活性位点的完整酶。

**TetR / 2XPU为第二候选**：前11个中8个命中源口袋且在TDC的6Å内，9个在8Å内，最大CA8Å连通分量8个；仍有3个分散的注释外高分。前10%为12/22命中，precision54.5%、recall52.2%。来源配体为anhydrotetracycline，原结构研究为“反式调控/变构并不依赖二价金属识别”，DOI `10.1021/bi5012805`。本图只显示链A及源TDC，未显示装配体其余链。202个观测残基完成映射，其中1个与参考序列不一致，保持灰色；精确位置见映射底表。

**FadR / 1H9G作为备选**：前12个中10个在源配体6Å内，8个在给定口袋注释中；说明有部分注释外高分仍靠近配体，不能据此全部断言为新真阳性。CTP案例和TetR案例的注释精度更高。出处DOI `10.1093/emboj/20.8.2041`。

### 为什么没有直接采用最高分的FKBP12？

FKBP12 / 1NSG的数值更高，但它是FKBP12–rapamycin–FRB三元复合物，容易把配体介导的伙伴招募与本文希望说明的调节口袋概念混淆，且score基线同样能命中5/6。故不因最高数值直接优先展示。该排除理由记录于来源JSON，未删除其筛查结果。

## 图形与可复现性

### 1ZA2注释外两个高分确为亚基接触：已独立核对

不能仅看蓝色区域猜测界面。本次按PDB的REMARK350 biological assembly1重建3个BIOMT操作、A–D链的12聚体，以链B在identity操作下为目标，对其他所有生物学装配体蛋白链计算非氢原子最短距离（altloc为空/A）。不是任意晶体邻居。

hidden固定top8的6个CTP来源口袋命中为A11、I12、V17、L58、K60、I86；另外两个高分是**Q24、F27**。Q24距源CTP16.15Å，但距同一装配体调节链D的T38仅3.373Å；F27距CTP15.63Å，但距D链S31仅3.186Å。两个均通过4Å和5Å接触定义。因此本例可描述为“前8位高排名包含6个CTP注释口袋残基及2个调节亚基界面残基”。六个口袋命中与其他链的最近距离均大于5Å，当前选中两类区域可区分。

这是独立几何核对，并非为了口袋精度将2个注释外高分重新改成变构正例。原口袋precision仍为6/8=75%、recall6/12=50%；不能将界面两个补成“口袋准确率100%”。也不代表识别完整界面、证明双任务训练或发现新的调控路径。hidden探针是经AlloBench标签拟合的，不是未经下游拟合的零样本发现。

接触底表：`1ZA2/TOP5_BIOLOGICAL_CONTACTS.csv`、`ALL_RESIDUE_BIOLOGICAL_CONTACTS.csv`、`CONTACT_PROVENANCE.json`；显示真实链D的结构上下文图为 `1ZA2/top5_pocket_and_interface_context.png/pse`。完整生物学装配体已用于距离核对，图只显示B/D调节链对，其他链不显示，不暗示仅有二聚体构成整酶。

### 界面独立着色版

`1ZA2/interface_aware_comparison.png/pdf`将已核对的直接蛋白界面加入原变构比较图：**深青绿为高分界面残基，浅青绿为界面背景**；红为口袋命中，橙为口袋遗漏，紫色为两类均非的其他高分，灰为其余位置。配体仍为紫色sticks，和残基surface通过表现形式区分。完整界面由生物学装配体≤5Å蛋白非氢原子接触定义，独立于预测阈值，不是只给Q24/F27事后贴上“界面”标签。第一列显示全部来源口袋与界面背景，后三列叠加各探针选择结果。

hidden top5%为6个口袋命中＋2个界面命中；top10%为7个口袋命中＋9个界面命中。这不把两类混成一个新指标，口袋precision仍为75%和43.8%。原生score在可映射top5%中6个位点为界面，另外2个全蛋白top8位置没有当前链坐标；图下注明“Mapped”，不将未显示位置视作零个其他高分。所有方法的全蛋白预算未改变。界面和口袋若重叠用专门overlap色，不覆盖类别；本链当前注释两类无重叠。逐残基类别见 `INTERFACE_AWARE_TOPK.csv`，颜色定义见 `INTERFACE_FIGURE.json`，PyMOL会话同目录保留。

预览位于 `figures/structural_cases/pocket_screen/` 的 `1ZA2_pocket_comparison.png`、`2XPU_pocket_comparison.png`、`1H9G_pocket_comparison.png`，均另存PDF。各图两行预算一致，第一列为来源注释，后面是score、structure、hidden。红为命中，橙为遗漏，蓝为注释外高分；全部可映射高分保留，同相机，不通过旋转单个方法或只截口袋局部藏掉散点。

每例子目录保留PDB、PSE、完整蛋白预测、序列映射、逐方法top-k分类。颜色类别对照源码及结构空间量化在 `CANDIDATE_SPATIAL_SUMMARY.csv`；真实源配体重原子距离、CA连通阈值为描述性几何，不是口袋识别算法或显著性检验。缺失坐标与序列不一致不冒充低分，precision分母始终为全蛋白固定k。探针输入仍是保存的单体表示，展示复合物没有参与读出拟合。

这些案例支持“高排名残基在已知配体口袋富集”，不等于准确恢复完整口袋边界。主图若使用top5%，必须在图注说明固定预算，并在补充保留top10%敏感性和完整筛查，避免只展示最佳阈值。此前来源测试折选优的探索性边界依然适用。
