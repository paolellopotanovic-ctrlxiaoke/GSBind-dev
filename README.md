# M4

M4 predicts protein-interface residues from a receptor-only protein structure.
This repository exposes the exact validated scientific implementation through a
small training, cache, evaluation, and label-free inference API.

## What is included

```text
main.py                     train, labeled evaluation, and four cache builders
inference.py                label-free per-residue prediction
src/m4/                     public API and exact validated implementation
configs/                    paper experiment configurations
scripts/dataset/            Pinder construction, union, selection, and leakage audit
assets/                     immutable checkpoint and dataset registries
examples/inference/         runnable receptor-only PDB example
docs/                       data, checkpoint, experiment, and validation protocols
```

The compatibility layer preserves model tensors, checkpoint keys, forward
computation, losses, and optimizer behavior. Five critical sources are pinned
by SHA-256 and checked by CI.

## Installation

```bash
conda env create -f environment.yml
conda activate m4
python scripts/verify_sources.py
```

CUDA is required for the validated static-geometry builder and practical M4
inference. The reference environment is PyTorch 2.1.2 with CUDA 12.1.

## Download the checkpoint

Checkpoints are release assets, not ordinary Git blobs. The primary checkpoint
is registered as an immutable v0.1.0 GitHub Release asset:

```bash
python scripts/download_checkpoint.py m4_holo20k_v9_clean_epoch4
python scripts/validate_checkpoint.py \
  checkpoints/m4_holo20k_v9_clean_epoch4.pt \
  --registry-name m4_holo20k_v9_clean_epoch4
```

The expected checkpoint is 46,437,755 bytes with SHA-256
`d6b418e21d8fc43f347f7c4438e2339877dd3afb240c6196aa7eff896caaee14`.

## Label-free inference

`predict` does not read biological labels or calculate AUPR/AUROC. It exports
one probability row per input residue. Start with the included 46-residue PDB:

```bash
python main.py prepare-input --pdb examples/inference/1CRN.pdb \
  --case-id 1CRN --input-state apo --output work/1CRN/manifest.csv
```

Build tensor, residue-graph, SHRake surface, and static-geometry caches, then:

```bash
python inference.py --manifest work/1CRN/manifest.csv \
  --checkpoint checkpoints/m4_holo20k_v9_clean_epoch4.pt \
  --output-dir work/1CRN/predictions \
  --tensor-cache-dir work/1CRN/tensor \
  --residue-graph-cache-dir work/1CRN/graph \
  --s1-surface-cache-dir work/1CRN/surface \
  --s1-static-geometry-cache-dir work/1CRN/static
```

The complete cache commands and output schema are in
`examples/inference/README.md`. Technical zero labels generated by
`prepare-input` exist only to preserve legacy cache keys; inference never treats
them as observations.

## Reproduce the Holo20k experiment

1. Follow `docs/DATASET_BUILD_CHECKLIST.md` to generate Pinder-train holo
   contact events, union all partners, enforce cluster/distribution constraints,
   and run the mandatory three-source MMseqs2 audit.
2. Download the exact paper manifest with `scripts/download_dataset.py`, or
   compare a rebuilt manifest to the registered SHA-256.
3. Build all four cache families and require `scripts/audit_cache.py` to pass.
4. Run `python main.py train --config configs/m4_holo20k.yaml`.
5. Evaluate GPSFun, Pinder-S apo, and Pinder AF2 with `main.py eval`.

The exact v9 manifest has 20,000 unique structures, 9,812 clusters, cluster cap
20, and zero MMseq30/cov80 hits. Dataset statistics and the immutable manifest
hash are registered in `assets/datasets.json`.

## Release status

CPU tests, source hashes, tracked-only installation, and strict E4 checkpoint
loading pass. The v0.1.0 code/checkpoint bundle is a prerelease; same-GPU
old/release logit equivalence, deterministic one-step training equivalence, and
publication of the exact dataset artifact remain mandatory before claiming
exact end-to-end scientific reproduction. See `docs/VALIDATION.md`.
